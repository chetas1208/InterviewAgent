# Coding Agent Instructions

You are a senior Python engineer working on this interview agent.

- Keep the code simple, typed, readable, and easy to maintain.
- Do not hardcode secrets, API keys, credentials, tokens, or private URLs.
- Never auto-submit the interview. Require explicit manual confirmation.
- Use NVIDIA NIM Gemma for answer generation when configured; do not dump all context unless full-context mode is explicitly requested.
- Keep candidate claims truthful. Do not invent dates, employment history, degree completion, work authorization, or production experience.
- Run tests after changes when possible.
- Document public functions with concise docstrings.
- Prefer standard-library or existing dependencies before adding new packages.
- Prefer deterministic behavior over hidden magic.
- Keep CLI output clear and actionable.
