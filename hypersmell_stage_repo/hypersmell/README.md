# Hypersmell

Scent memory platform for fragrance professionals. Companies connect their data sources
(formulation databases, supplier catalogs, tasting notes), Hypersmell ingests and indexes
the content, and perfumers search across their scent knowledge base through an API.

"Scent has the strongest memory recall — Hypersmell makes sure you never lose one."

## Quick Start

```bash
task up       # Start all services
task migrate  # Run database migrations
task test     # Run tests
```

See `CLAUDE.md` for development conventions.
